# Методичка CRM RoApp - Tesla Company

Интерактивная методичка по регламенту работы с CRM RoApp (версия от 27.10.2026).

Один файл: `index.html`. Без сборки и зависимостей, шрифты подтягиваются с Google Fonts.

## Как открыть локально

Откройте `index.html` в браузере.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий и загрузите `index.html` и `README.md` в корень.
2. Settings, затем Pages.
3. Source: Deploy from a branch, ветка `main`, папка `/ (root)`, Save.
4. Через минуту-две страница будет доступна по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
